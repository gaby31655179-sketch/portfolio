管理作品與履歷

使用 GitHub 帳號登入編輯頁面，透過表單修改內容。

  1. 開啟編輯頁面並登入 GitHub。
  2. 選擇這個網站的儲存庫與 main 分支。
  3. 在「作品」新增、修改、排序作品，或上傳圖片與 PDF。
  4. 在「履歷」修改文字，或上傳新版履歷 PDF。
  5. 按儲存，等待 GitHub 完成發布後再重新整理網站。
開啟線上編輯頁面 ↗

第一次使用時，Pages CMS 會請你授權存取網站儲存庫。登入與授權在 GitHub 的正式頁面進行。

若看不到「作品」與「履歷」，請先確認網站檔案已上傳到 GitHub，並選到含有 .pages.yml 的分支。
