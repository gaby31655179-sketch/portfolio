# 作品與履歷：本機編輯版

## 怎麼開啟

1. 雙擊資料夾裡的 **啟動網站.cmd**。
2. 保留啟動後的視窗。
3. 在瀏覽器開啟：
   - 網站：http://127.0.0.1:4173/
   - 備用完整管理頁面：http://127.0.0.1:4173/admin/

若顯示連接埠已使用中，先用以上網址查看是否已經啟動。

## 怎麼修改

直接在網站上操作：

- 點「作品」或「＋ 新增作品」，直接填寫新作品。
- 點作品卡片或卡片的「編輯作品」，修改該作品。
- 點「履歷」、履歷內容或「編輯履歷」，修改履歷與上傳 PDF。
- 按「儲存」後，視窗關閉，首頁即更新。

作品可以附上網址、圖片和 PDF。若需要一次編輯全部作品、調整順序或移除作品，可使用備用完整管理頁面。

檔案支援 PDF、PNG、JPG、WEBP，單一檔案最多 8 MB。上傳後按 **儲存**，看到「已儲存，網站已更新！」即可。

修改內容真正寫入此資料夾，關閉服務或重新啟動電腦後仍會保留。移除作品或檔案連結時，原始上傳檔案仍留在 uploads 資料夾。

使用完畢可關閉啟動視窗。下次再雙擊「啟動網站.cmd」即可繼續。

## 資料放在哪裡

- `data/resume.json`：履歷內容。
- `data/projects.json`：作品內容。
- `uploads/`：圖片與 PDF。
- `_site/`：儲存後產生的網站預覽。

備份時複製整個網站資料夾即可。日常使用以上本機網址查看與修改最新內容，不需要自己修改這些檔案。

## 目前狀態

本機服務只接受這台電腦的連線。網站原始碼與資料使用 GitHub 儲存庫保存：

https://github.com/gaby31655179-sketch/portfolio

儲存庫保留私人設定，尚未發布到公開網路。本機按儲存會更新此資料夾，並不會自動同步 GitHub。

GitHub Pages 與 Pages CMS 的設定仍保留，之後要上線時可繼續使用。

## 日後公開上線與線上編輯

確認網站內容可以公開後，依 GitHub 方案設定 Pages（GitHub Free 通常需要公開儲存庫）。到 Settings → Pages，將 Source 設為 GitHub Actions；再到 Settings → Secrets and variables → Actions → Variables，新增 `ENABLE_PAGES`，值填 `true`，並執行 Check and publish portfolio 工作流程。

上線前工作流程只檢查網站，不會嘗試部署。

GitHub Pages 為靜態網站，不會執行本機的 `server.cjs`。目前的首頁點選編輯功能由本機服務提供；線上版使用網站頁尾的「管理內容」進入 Pages CMS，登入 GitHub 並授權此儲存庫後，以「作品」與「履歷」表單編輯。儲存到 main 分支後，GitHub Actions 會更新公開網站。

如果日後也要在線上首頁直接點選編輯，需要另加登入與寫入服務；目前沒有開放訪客修改網站內容。

## 程式檢查

已通過 `node verify-local.cjs` 的實際 HTTP 測試：讀取、儲存、PDF 與圖片上傳、更新網站、重新啟動後保留資料，以及錯誤輸入與跨來源請求處理。測試使用暫存資料夾，不修改你的履歷與作品。

`node verify.cjs` 檢查網站內容呈現與 GitHub Pages 路徑。已在瀏覽器實測首頁新增作品視窗、點選履歷編輯，以及儲存後更新首頁；另有 `node verify-editor.cjs` 檢查連線失敗後的重試狀態。
